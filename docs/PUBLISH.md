## 一句话描述

- 64 位整数计算器，带位图和字段读写
- 算表达式、看位图、按字段读写 64 位整数
- 调试寄存器时用的 64 位计算器

用第一个就行：位宽和两个主要功能都说了，不夸张。

## 插件应用介绍

```
bitcalc 是一个 64 位的位运算计算器。输入表达式，结果同时按 HEX、DEC、OCT、BIN 显示，并标在 64 格位图上。

常用的三个操作：

1. 计算
支持 + - * / % ** << >> & | ^ ~ 和括号，0x / 0b / 0o 字面量，数字里可以加下划线；有 popcount、rotl、rotr、bswap、bitrev、clz、ctz、asr 等 13 个函数。结果按当前位宽截断。

2. 按位段读写
在 64 格位图上按住拖一段，比如 63:60，读数就只显示这 4 位；这时输入 0x5 回车，也只改这 4 位，其他位不动。单个位可以直接点翻转；选区能一键扩到字节、16 位、32 位，也能置 0、置 1、清空。右键或 Esc 取消。

3. 定义字段
字段窗口里一行一个定义：opcode 15:12、mode:4（从上一段末尾继续分配）、flag 0:0、# 注释。右边实时解码出 U/S、HEX、BIN；重名、位号非法、越界、重叠会提示。定义可以存成命名方案，也能导出、导入 JSON。

另外：

- 位宽 8 / 16 / 32 / 64，有无符号和大小端可选；32 位及以上能看 F32，64 位能看 F64。
- Ctrl/Cmd+Z 撤销，Ctrl/Cmd+Shift+Z 重做；输入框 ↑ / ↓ 翻表达式历史。
- 按 ? 打开内置帮助，运算符优先级、函数、字段语法、快捷键都在里面。
- 关键词两个：bitcalc、位运算计算器；输入含 0x / 0b / 0o 数字或含 & | ^ ~ << >> 的表达式，也会直接命中「位运算计算」。

数据都在本地：设置存 uTools 存储，历史写到插件数据目录（最多 200 条），插件不联网。
```
