表达式

支持十进制、0x 十六进制、0b 二进制、0o 八进制和下划线分隔。计算按 64 位无符号位模式进行，结果会按当前位宽截断。

  • 0xFF & 0x0F、(1 << 12) - 1
  • popcount(0xDEADBEEF)、rotl(0x1234, 8)
  • >> 是逻辑右移；asr(x, n) 是按当前位宽符号位扩展的算术右移。
  • 除法向零截断；表达式错误时保留当前值。

位图与位段

  • 点击位翻转 0/1。
  • 在位图上按住并拖动，可以选中一段位进行部分位使能。
  • 右键或 Esc 取消位使能，不改变当前值。
  • 使能后，主读数与表达式按该位段计算，段外位不可点击。
  • 直接在计算框输入表达式并回车，即可只写入使能的位段。
  • 界面底部的字段值点击后会选中该字段位段，计算框中可直接修改。

字段定义

opcode 15:12
dst 11:8
src 7:4
mode:3
flag 0:0
  • name 15:12：显式位段。
  • name:4：从游标向下分配 4 位，游标从有效位宽最高位开始。
  • name 7：单 bit 字段。
  • # 或 // 后为注释；空行忽略。
  • 重名、越界会报错；重叠会提示，但字段仍可用于解码。
